## Run the app and Storybook

1. Install dependencies: `npm install`
2. Start Expo: `npm start`
3. Open the project on a device or simulator (QR code in the terminal, or press **`i`** / **`a`**), or press **`w`** for **web** and use the URL Expo prints.

| What        | Where                         |
| ----------- | ----------------------------- |
| **App**     | Home route `/` (default)     |
| **Storybook** | Route **`/storybook`**      |

On web, go to **`/storybook`** on the same origin as the tab Expo opened (path only: add `/storybook` to that URL).

You can also run **`npm run web`** instead of `npm start` if you only want the browser.
